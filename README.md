### 🔄 Azure DevOps CI/CD Pipeline
- Built an automated Azure DevOps CI/CD pipeline to validate and deploy infrastructure changes through a controlled Git-based workflow.

# Pipeline Flow:

                Git Push / Pull Request 
                          ↓
                     Azure Pipeline  
                          ↓
                   Terraform Format
                          ↓
                   Terraform Validate
                          ↓
                    Terraform Plan
                          ↓
                     Approval Gate
                          ↓
                    Terraform Apply
                          ↓
                  Azure Infrastructure
                  

- YAML-based Azure DevOps pipeline
- Automated Terraform fmt, validate, plan and apply
- Git-based source control and Pull Request workflow
